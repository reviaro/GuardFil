# GuardFil v0.1.0-alpha.5

The alpha.5 tag check exposed an intermittent concurrent-startup error. For installation, use [alpha.6](v0.1.0-alpha.6.md).

This patch release updates the build and agent runtime images to Go 1.27.4 and fixes provider ledger migration and initialization. It supports single-user evaluation on Linux with Docker and FUSE.

## Install or upgrade

Follow the [tagged quickstart](https://github.com/reviaro/GuardFil/blob/v0.1.0-alpha.5/README.md#quickstart). Existing installations should rebuild the image and extract the new host helpers by running `deployments/local/guardfil-local.sh up` from the new checkout.

If you have provider ledgers from alpha.3 or earlier, stop active agents and inspect the planned migration before applying it.

```sh
"${GF_HOME:-$HOME/.guardfil-local}/bin/guardfil-broker" migrate-ledger --provider all --dry-run
"${GF_HOME:-$HOME/.guardfil-local}/bin/guardfil-broker" migrate-ledger --provider all
```

Existing schema-v2 ledgers keep their balances, reservation counts, and halt status. An interrupted alpha.4 installation that lacks matching recovery records still requires a known matching backup.

## Changes

- Healthy legacy ledgers must have settlement records that match their journal before migration. The dry run performs the same settlement checks.
- Interrupted first-time initialization and migration of an empty or evidence-only legacy directory can resume without giving an existing ledger a second spending allowance.
- The Claude Messages broker streams signed thinking blocks in the order the client needs for follow-up tool turns.
- One-shot Codex runs exit with an error when the native agent reports a failed or interrupted turn.
- The source build, hosted CI, and default executor use the digest-pinned Go 1.27.4 image.

See the [budget guide](https://github.com/reviaro/GuardFil/blob/v0.1.0-alpha.5/docs/guide/models-and-budget.md), [evaluation limits](https://github.com/reviaro/GuardFil/blob/v0.1.0-alpha.5/README.md#limits), and [private reporting policy](https://github.com/reviaro/GuardFil/blob/v0.1.0-alpha.5/SECURITY.md).
